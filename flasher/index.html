KOYETI · HSK 1–2

Firmware v@VERSION@ · commit @COMMIT@ · built @DATE@ · ESP32-C3 + SSD1306 OLED
This browser can't flash devices. Use Chrome or Edge on a computer. Flashing needs HTTPS. Open this page from its github.io address.

Plug in the ESP32-C3 with a USB data cable, click Install and pick its port.

Using it

  • Long press – start or stop review.
  • Tap – next page: hanzi → pinyin → meaning → every HSK 1–2 word with that character.
  • Double tap – another random card. On the face: send a heart to the partner device.

Prefer a single file?

Download KOYETI-HSK-esp32c3.bin and flash it at address 0x0 with Espressif's web flasher or esptool --chip esp32c3 write_flash 0x0 KOYETI-HSK-esp32c3.bin.

If it doesn't connect

  1. No port listed → try another cable (many are charge-only). Boards with native USB show up as “USB JTAG/serial debug unit”; boards with a CH340 chip need the CH340 driver.
  2. “Failed to connect” → hold BOOT while plugging the USB cable in (or hold BOOT and tap RESET), release BOOT, then click Install again.
  3. After flashing, press RESET or unplug and replug if the screen stays blank.
  4. Close Arduino IDE's Serial Monitor first — only one program can use the port.

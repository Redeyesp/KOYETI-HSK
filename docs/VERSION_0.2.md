# Koyeti v0.2

## Behavior

- Default screen: Normal face
- Automatic blink every 8–15 seconds
- Long press: enter or leave review mode
- Single tap in review: next information page
- Double tap in review: random next kanji
- Leaving review: Happy face for 1.5 seconds, then Normal face
- Kanji bitmap is enlarged 3× (16×16 to 48×48)

## Pins

- Touch: GPIO 7
- OLED SDA: GPIO 8
- OLED SCL: GPIO 9

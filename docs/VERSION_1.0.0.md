# Koyeti v1.0.0 — Simple N2 Companion

This version intentionally contains only the minimal daily-review interaction:

1. Smile is the default screen.
2. Long press enters review with a random card.
3. Single tap advances through card information.
4. Double tap changes to a different random card.
5. Long press returns to the smile.

No menus, SRS, battery state, statistics, Wi-Fi, or animated emotion system are included.

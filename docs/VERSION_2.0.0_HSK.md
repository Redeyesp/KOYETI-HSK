# Koyeti v2.0.0 — HSK 1–2 Companion

Converted from the JLPT N2 kanji version.

- 347 hanzi cards covering all HSK 2.0 level 1–2 words (302 words).
- Pages: hanzi (with HSK level) → pinyin → meaning → every HSK 1–2 word using the character.
- Chinese glyph shapes from standard GNU Unifont 15.1.01 (was Unifont-JP).
- Pinyin with tone marks drawn from Unifont glyphs (new `LatinStyle::Unifont` text mode).
- `build_all.py --lang th` switches the device meanings to Thai.
- Review history uses a new NVS namespace (`koyeti-hsk`), so old N2 history is ignored.
- Touch controls, face animations, sleep and the ESP-NOW partner heart are unchanged.
